# Design Reference Catalog

Use this catalog when the user does not specify a brand reference. Pick the reference whose product context and density match the task, then read the actual source file before applying it.

## AI and Developer Products

- `claude`: Warm editorial AI interface, parchment surfaces, terracotta accent, thoughtful and calm.
- `cursor`: Dark AI coding product, sleek gradients, developer-first.
- `warp`: Terminal-like dark interface, command blocks, warm technical tone.
- `supabase`: Dark emerald developer platform, code-first surfaces.
- `voltagent`: Agent framework feel, void-black canvas, emerald accent, terminal-native.
- `vercel`: Precise black-and-white developer platform, clean and restrained.
- `linear.app`: Minimal dark-mode operations UI, dense, exact, purple accent.
- `raycast`: Polished productivity chrome, dark UI, vibrant accents.
- `sentry`: Data-dense monitoring dashboard, dark surfaces, pink-purple emphasis.

## Documentation and Knowledge Work

- `mintlify`: Reading-optimized docs, clean surfaces, green accent.
- `notion`: Warm minimalism, soft surfaces, quiet workspace mood.
- `replicate`: Clean white canvas, code-forward ML documentation.
- `mongodb`: Developer documentation with green identity and structured layout.
- `sanity`: Content-first editorial style with red accent.

## Marketing and Landing Pages

- `stripe`: Premium SaaS marketing, purple gradients, elegant type hierarchy.
- `framer`: Bold design-forward marketing, black and blue, motion-friendly.
- `webflow`: Polished visual-builder marketing, blue accent.
- `apple`: Premium white space, cinematic product focus.
- `spacex`: Stark black-and-white, full-bleed imagery, futuristic.

## Friendly Consumer and Collaboration

- `airbnb`: Warm coral, photography-driven, rounded and approachable.
- `figma`: Multi-color creative collaboration, playful but professional.
- `intercom`: Conversational blue UI, friendly support/product tone.
- `miro`: Bright yellow infinite-canvas collaboration.
- `pinterest`: Image-first masonry layouts and red accent.

## Saved Figma Component Kits

- `HeroUI Figma Kit Community`: Reusable application UI components, variants, states, and token-driven dark/light patterns. See `figma-kits.md` and inspect the exact component node before implementation.
- `Interactive Portfolio Website UI Design`: Community source for modern portfolio composition and interaction ideas. Duplicate it into Figma and provide a node-specific design link before detailed implementation. See `figma-kits.md`.

## Live Code Components

- `Select Codes`: Production-oriented React, Next.js, Tailwind CSS, and Motion components with live previews, readable source, AI prompts, and shadcn-compatible installation. See `code-components.md`; verify current dependencies and license terms before use.

## Finance, Trust, and Data

- `coinbase`: Clean blue trust-focused finance UI.
- `wise`: Bright green, friendly clarity for money movement.
- `revolut`: Dark fintech precision with gradient cards.
- `kraken`: Purple-accented dark trading dashboards.

## Premium Physical Products

- `bmw`: Dark premium surfaces, precise engineering, vehicle/product focus.
- `nvidia`: Green-black technical power aesthetic.
- `uber`: Bold black-and-white, urban and direct.

## Practical Pairings

- Internal analytics dashboard: `linear.app` plus a small amount of `sentry`.
- AI assistant app: `claude` plus `replicate` for code/content surfaces.
- Korean family or health app: `intercom` or `airbnb`, with accessibility tightened beyond the reference.
- Vehicle dashboard: `bmw` for product mood plus `coinbase` or `vercel` for clean data cards.
- Research wiki: `notion` plus `mintlify`.
- Motion-rich React interface: a restrained structural reference plus `Select Codes` for implementation behavior.
