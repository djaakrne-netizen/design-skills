## HeroUI Figma Kit Community

- Locate a publicly accessible HeroUI Community kit or use a file link supplied for the current task. No personal saved Figma file key is bundled.
- Inspect the selected file and its current pages before claiming which components it includes.

### Selection guidance

- Use `Chip` for standalone status labels such as `진행 중`, `완료`, or category tags.
- Use `Badge` for a count or small notification indicator attached to another element.

- For implementation, select the exact component or variant in Figma, copy its design link, and use the resulting `node-id` for design context and screenshot inspection.
- Verify accessibility, Korean text expansion, and the current project's tokens before adopting a component.
